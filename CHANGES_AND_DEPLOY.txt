HOW TO PUBLISH ON GITHUB PAGES
1. Keep your current GitHub repository as a backup, or download its current code.
2. Extract this ZIP. Copy the files INSIDE the usman-portfolio folder into the
   same GitHub Pages directory that currently contains your index.html.
3. Commit the file changes. GitHub Pages will redeploy from your configured branch.
4. After deployment, refresh the site (Ctrl+Shift+R) and check the homepage order,
   all four case-study links, and the Meridian prototype link.

Do not present the concept screens or heuristic walkthrough as clinical validation,
real-world user test results, or a production accessibility audit.
